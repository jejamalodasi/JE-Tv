# JE-Tv
# Advanced IPTV Playlist Pipeline

Features
- Auto-build playlist.m3u from playlist.csv
- Handles missing Logo, Group, EPG_ID columns
- UTF-8 support
- Manual and scheduled builds
- Artifact upload after every run
